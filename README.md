# Fraction Lab

A one-page site for learning fractions. It's plain HTML, CSS, and JavaScript in `index.html`, with no libraries.

## What's in it

- **Lessons:** Add, Subtract, Multiply, Divide (Keep Change Flip), and Cross Cancel
- **Step-by-step animations:** click through each example or press Play
- **Steps / Why / Why it matters** cards for every lesson
- **In the classroom** ideas and common mistakes to call out
- **Practice:** random problems, pick which operations, checks your answer and keeps score
- **Search:** type a topic like "common denominator" or "keep change flip"

## Hosting

GitHub Pages deploys the site from `main` using `.github/workflows/static.yml`.
